4. 获取 GitHub 变量

  1. 打开 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  2. Resource owner 选择你的账号；Repository access 只选择博客仓库。
  3. Repository permissions 中把 Contents 设置为 Read and write，生成后立即复制到 GITHUB_TOKEN。
  4. 仓库网址若是 github.com/alice/my-blog，则 GITHUB_REPOSITORY 填 alice/my-blog。

参考：GitHub 创建 fine-grained token 官方文档。Token 等同密码，请放在 Secret 环境变量中。

5. 文章位置与可选变量

GITHUB_BRANCH

博客仓库的默认分支，通常是 main；不填也默认使用 main。

POSTS_PATH

文章目录。Hexo 通常是 source/_posts（默认值），Hugo 常见为 content/posts，以你的仓库结构为准。

POST_EXTENSIONS

可编辑扩展名，默认 .md,.markdown。

SESSION_AGE

登录有效秒数，默认 604800（7 天）。Vercel 默认启用安全 Cookie 和 HTTPS 跳转；其他 HTTPS 部署可设置 COOKIE_SECURE=1、SSL_REDIRECT=1。

LLM_API_KEY / LLM_MODEL

可选的 AI 文章优化配置。设置后编辑页会启用 AI 处理，密钥只在服务端使用。

LLM_BASE_URL

OpenAI 兼容 API 地址，默认 https://api.openai.com/v1。自托管或第三方兼容服务可覆盖此值。

LLM_API_STYLE

可选 auto、chat 或 responses，默认 auto，会自动在 chat/completions 与 Responses API 之间切换。
